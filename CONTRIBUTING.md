# Flujo de trabajo del equipo

- Rama principal: `main` (siempre estable).
- Una rama por tarea: `feature/<tema>` (por ejemplo `feature/recordatorios`) o `fix/<tema>`.
- Mensajes de commit en español, en presente: `Agrega validación de DNI en el registro`.
- Cada cambio entra por Pull Request con revisión del otro integrante.
- Las tareas se registran como Issues y se agrupan en Milestones `Sprint 1` y `Sprint 2`.
